# Week 1 – JavaScript Fundamentals

This folder contains the JavaScript programs completed during Week 1 of practice. The main goal of these exercises was to build a strong foundation in JavaScript by working with basic programming concepts such as conditional statements, loops, functions, and array operations.

These programs demonstrate simple problem-solving approaches and help in understanding how JavaScript works through hands-on examples.

## Prerequisites

Make sure the following is installed before running the programs:

- Node.js
- Terminal / Command Prompt

## How to Run the Programs

Open the folder in your terminal:

```powershell
cd c:\week6\ATP_24EG105D09\week1
```

Run any file using Node.js:

```powershell
node filename.js
```

Example:

```powershell
node largestOf2.js
```
