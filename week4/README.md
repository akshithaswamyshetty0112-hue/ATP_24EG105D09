# Week 4 - Basic HTML Webpages

This folder contains simple HTML practice webpages created during Week 4. The exercises focus on understanding the basic structure of an HTML document and using common HTML tags to organize webpage content.

## Technologies Used

- HTML5

## Folder Structure


week4/
|-- pochi-cat.html
|-- webpage.html
|-- fruits&vegetables(lists).html
|-- README.md

## Files Description

### pochi-cat.html

This webpage is a simple profile-style page about "Pochi the Cat". It demonstrates how to organize content using headings, paragraphs, images, lists, links, and horizontal lines.

Features included:

- HTML document structure
- Main heading and subheadings
- Paragraph content
- Image with src, alt, width, and alignment attributes
- Ordered list for profile details
- Unordered list for links
- Anchor tags for hyperlinks
- Horizontal line using <hr>

### webpage.html

This webpage is a basic HTML page used to practice text content and list formatting. It includes paragraphs, a heading, a hyperlink, and an unordered list of fruits.

Features included:

- HTML document structure
- Paragraphs
- Heading tag
- Hyperlink using <a>
- Unordered list using <ul> and <li>
- Basic webpage content formatting

## Concepts Practiced

The following HTML concepts were practiced in this folder:

- Basic HTML boilerplate
- DOCTYPE, html, head, and body tags
- Meta tags
- Page titles
- Headings and paragraphs
- Images and image attributes
- Hyperlinks
- Ordered and unordered lists
- Horizontal lines
- Basic content organization
### nested-list.html

This webpage is a simple nested list page that displays different food categories and their items. It demonstrates how to create lists inside other lists using HTML unordered lists.

Features included:

- HTML document structure
- Unordered lists using <ul>
- List items using <li>
- Nested lists for subcategories
- Food categories and related items
- Proper indentation and hierarchy of content

### index.html

Contains the HTML code for displaying the nested food list webpage.
