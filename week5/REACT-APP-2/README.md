# Week 5 – React Components and State Management

This project contains a React application developed during Week 4 using React and Vite. The main objective of this project was to understand React fundamentals such as components, props, forms, state management, and building reusable UI elements.

The application includes different practice components that demonstrate concepts like form handling, counters, API fetching, and displaying user data. The project also uses Tailwind CSS for styling and React Hook Form for handling forms efficiently.

## Technologies Used

- React
- Vite
- Tailwind CSS
- React Hook Form
- ESLint

## Prerequisites

Before running the project, make sure you have:

- Node.js installed
- npm installed

Check installed versions:

node -v
npm -v


## Installation

Install all project dependencies:


npm install


## Running the Project

Start the development server:

npm run dev


Open the local server URL displayed in the terminal:


http://localhost:5173
