# Week 5 Remaining Files

This README documents the loose files kept directly in the `week5` folder.

## Files

- `table1.html` - A standalone HTML page that displays a simple table with a title, subtitles, and repeated item rows.
- `style.css` - Styles used by `table1.html`, including table width, spacing, borders, and centered alignment.
- `tmp` - A small placeholder file.

## How to Run

Open `table1.html` in a browser. The page automatically loads `style.css` from the same folder.
