# Week 2 – Cards Layout Webpage

This project contains a simple static webpage created using HTML and CSS. The main purpose of this project was to practice webpage layout design and understand how styling can improve the appearance of a website.

The webpage includes a navigation bar and multiple content cards arranged in a clean layout. Through this project, I practiced concepts such as Flexbox, card design, spacing, alignment, and styling using CSS.

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Project Structure


proj2/
├── cards.html
├── style.css
└── README.md


## Features

- Navigation bar with centered menu items
- Hero section with background styling
- Multiple card layout using Flexbox
- Circular images inside cards
- Category tags with different styles
- Responsive and clean design structure
- Card styling using borders, spacing, and shadows

## File Description

### cards.html

Contains the structure of the webpage including:

- Navigation bar
- Hero section
- Content cards
- Images
- Titles and descriptions

### style.css

Contains all styling related to:

- Layout design
- Card appearance
- Flexbox alignment
- Colors and spacing
- Typography and shadows

Inside `style.css`:
