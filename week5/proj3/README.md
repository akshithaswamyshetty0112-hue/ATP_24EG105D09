This project is a simple static webpage that displays a styled users table using HTML and CSS.

Project Files
table.html – Main HTML file containing a table with user information such as profile picture, name, email, phone number, and comments.
style.css – CSS file used for styling the table, images, spacing, borders, and overall page layout.
t – Placeholder file.
Running the Project

To run the project:

Make sure table.html and style.css are placed in the same folder.
Open table.html in any web browser.

The webpage will automatically load the styles from style.css.

About the Project

This project demonstrates basic HTML and CSS concepts, including:

Creating tables in HTML
Styling tables with CSS
Displaying profile images inside table rows
Managing layout, spacing, and borders
Organizing user information in a clean format
