This project is a simple static landing page titled “Libertarians”. It includes a top navigation bar, a hero section, an image section, and multiple content cards arranged in a clean layout.

Project Files
pagee.html – Main HTML file containing the structure of the landing page, including the top bar, headings, image, and content cards.
style.css – CSS file used for styling the layout, spacing, cards, typography, and overall visual appearance of the page.
t – Placeholder file.
Running the Project

To run the project:

Ensure both pagee.html and style.css are in the same folder.
Open pagee.html in any web browser.

The webpage will automatically load the styles from style.css.

About the Project

This project demonstrates basic web design concepts using HTML and CSS, including:

Landing page structure
Hero section design
Card-based content layout
Image placement and styling
Navigation bar styling
Basic responsive webpage formatting
