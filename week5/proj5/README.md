This project is a simple static webpage that includes a hero section and a set of informational cards. The page is designed using basic HTML and CSS.

Project Files
rp1.html – Main HTML file containing the hero section, heading, button, and three content cards.
style.css – CSS file used for styling the hero section, cards, buttons, spacing, and overall page layout.
t – Placeholder file.
Running the Project

To run the project:

Keep rp1.html and style.css in the same folder.
Open rp1.html in any web browser.

The webpage will automatically apply the styles from style.css.

About the Project

The webpage features:

A “Hello, world!” hero section
A call-to-action button
Three styled content cards
Basic responsive layout and styling using CSS

This project demonstrates fundamental concepts of HTML structure and CSS design.
