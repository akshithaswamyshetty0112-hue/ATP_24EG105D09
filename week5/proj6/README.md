This project is a simple static website called “Best City Guide”. It contains a navigation section, a city guide header, useful links, images, and content boxes styled using CSS.

Project Files
rp2.html – Main HTML file that contains the webpage structure, navigation bar, headings, links, images, and content sections.
style.css – CSS file used for styling the navigation menu, layout, images, header, and content boxes.
t – Placeholder file.
Running the Project

To view the project:

Make sure both rp2.html and style.css are in the same folder.
Open rp2.html in any web browser.

The webpage will automatically load the styles from style.css.

About the Project

The webpage is designed as a simple city guide layout with a clean structure and styled sections. It demonstrates basic HTML and CSS concepts such as:

Navigation bars
Page layout design
Styling with CSS
